# CrowdVote India - Project Overview

CrowdVote is a comprehensive nationwide Indian voting prediction platform. It allows users to predict election outcomes at the constituency level, starting with a focus on the upcoming Kerala elections.

## Core Objective
To harness collective intelligence for high-accuracy electoral forecasting while maintaining a simple, accessible UI for the general public.

## Key Features
- **Nationwide Coverage**: Support for all 28 States and 8 Union Territories.
- **State-to-Constituency Flow**: Multi-level selection hierarchy (State -> District -> Constituency).
- **Restricted Prediction**: Currently locked to Kerala for active elections, with other states under development.
- **Simplified UI**: Professional yet understandable terminology (e.g., "Prediction Center" instead of "Node Arena").
- **Swarm Intelligence**: Weighted scoring based on user history and confidence levels.
